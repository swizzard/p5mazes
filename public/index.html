change row (& column) length. default is 30

change the seen threshold, the percentage of cells that need to be visited before the algorithm stops. the algorithm will stop once (rowLength * rowLength) * (seenThreshold / 100) cells have been seen. default is 65.

change maze version. maze 1 is static; the rest erase walls over time.

change cell version. cell 0 is static, the rest erase 0 - 4 walls when created. thus, combining maze 1 & cell 0 will result in a static grid. it is recommended that you use cell 0 unless you want to use maze 1 and vice-versa.
